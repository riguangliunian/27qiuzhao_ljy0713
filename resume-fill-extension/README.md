# 简历投递填表助手 Chrome 扩展

这是一个本地 Chrome/Edge 扩展，用来在招聘投递页面自动填写重复字段。个人信息只保存在浏览器本地扩展存储里。

## 安装

1. 打开 Chrome 或 Edge。
2. 进入 `chrome://extensions/` 或 `edge://extensions/`。
3. 打开“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择这个文件夹：

```text
C:\Users\27260\Downloads\MAI-UI-main\resume-fill-extension
```

## 使用

1. 点击扩展图标。
2. 点击“设置个人信息”，填好常用信息、自定义字段和简历文件。
3. 打开招聘投递表单页面。
4. 点击扩展图标，再点“填写当前页面”。
5. 检查填写内容，手动上传简历或提交。

## 自定义字段

在设置页的“自定义字段”里可以直接添加字段，比如：

- 字段名：籍贯
- 要填写的内容：上海
- 匹配关键词：籍贯,户籍,生源地

保存后，只要网页字段附近出现这些关键词，插件就会自动填写。

## 从简历文本预填

PDF 自动解析中文不稳定，更稳的方式是复制简历文字到设置页文本框，然后点击“解析并预填”。它会尝试识别姓名、手机号、邮箱、学校、专业、学历、毕业年份、城市、籍贯等字段。

## 简历上传

不能只保存 `C:\xxx\resume.pdf` 这种本地路径来上传，因为网页和扩展不能随便读取你的硬盘文件，这是浏览器安全限制。

现在的做法是：你在设置页选择一次 PDF / Word 简历，扩展把文件内容保存到本地扩展存储。之后点击“填写当前页面”时，它会尝试把这个文件放进招聘网站的上传框。

少数网站会阻止脚本设置上传控件，这时仍需要手动选择文件。

## 实习经历 / 项目经历

对于页面里需要先点“添加”的板块，可以在设置页的“实习 / 项目经历”里配置。

每个经历卡片包含：

- 是否启用：默认关闭，避免误新增。
- 经历名称：比如实习经历、项目经历。
- 板块关键词：用于识别网页里的经历区域，比如 `实习经历,工作经历`。
- 添加按钮关键词：比如 `添加,+,新增`。
- 字段列表：和普通自定义字段一样，可以自由添加公司、岗位、部门、项目链接、技术栈、描述等。

为了避免误投，扩展不会自动点击最终提交按钮；也不会静默上传本地简历文件，只会高亮上传入口。
